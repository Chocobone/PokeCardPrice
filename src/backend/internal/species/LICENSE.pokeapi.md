# PokéAPI 라이선스

`pokemon_species_names.csv`는 PokéAPI 원본 데이터 `data/v2/csv/pokemon_species_names.csv`(커밋 `8d8a49d`, 2026-11-17 받음)에서
도감 번호와 영어(`en`, language 9)·일본어 가나(`ja-Hrkt`, language 1)·한국어(`ko`, language 3) 이름만 뽑은 것이다.
