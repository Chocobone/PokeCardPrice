조사 중 드러난 문제 때문에 계획에 없던 Scrydex와 TCGCSV도 추가로 확인했다.

## 발견 사항

1. **pokemontcg.io가 지원 종료 상태이다.** 신규 가입이 중단되었고 기존 키는 2027-03-01까지만 보장된다. 표본 호출 7회 중 3회가 500/502였다. 가격 갱신일도 TCGplayer 2026/10/15, Cardmarket 2026/07/01로 오래되었다.
2. **TCGdex의 TCGplayer 가격이 비어 있다.** 영어 카드 표본 8종 모두 `null`이다. Cardmarket 가격은 2026-10-31 값으로 갱신되어 있다.
3. **한글판 카드는 해외 API로 구성할 수 없다.** TCGdex의 한글 카드는 239장 / 9,521장(2.51%)이고, pokemontcg.io와 TCGCSV에서는 한글판을 찾지 못했다. 표본 1종에서 TCGdex 한글 카드의 가격은 일본판과 같은 Cardmarket 상품의 값이었으므로 국내 시세로 쓸 수 없다.
4. **소스 간 가격 차이가 크다.** Bulbasaur(`sv3pt5-1`)의 Cardmarket 평균가는 pokemontcg.io 79.89, TCGdex 0.13으로 약 615배 차이 난다. 상품 연결 오류를 의심하지만 확인하지 못했다.
5. **TCGCSV가 TCGplayer 시세 대체 후보이다.** 무키로 쓸 수 있고 전날 값이 갱신되어 있으며 2024-02-08부터의 일별 압축 파일을 제공한다고 안내한다. 다만 1인 취미 프로젝트이고, TCGplayer 데이터를 재공개할 권한과 라이선스는 확인하지 못했다.

## 계획과 달라진 점

- **조사 대상 추가**: 계획의 대상은 두 API였으나, 위 1·2번 때문에 대체 후보 Scrydex와 TCGCSV를 확인했다. Scrydex는 유료 계정이 필요해 문서만 확인했다.
- **표본 추가**: TCGplayer 누락 범위를 확인하려고 TCGdex 영어 카드를 5종 더 호출했다. 한글판 표본은 151 세트로 잡았으나 한글 데이터가 없어(404) `SV5K-001`을 별도로 확인했다.

## 접근 규칙 준수 점검

- **순서 위반 1건**: 첫 조사 때 `robots.txt` 확인과 pokemontcg.io·TCGdex 문서 조회를 동시에 실행해, "먼저 확인" 규칙을 지키지 못했다. 이후 확인한 결과 해당 경로에 차단 규칙은 없었다. API 도메인도 차단 대상이 아니었다(`api.tcgdex.net`은 주석에서 API 사용 가능 명시).
- **요청 간격 미보장 1건**: TCGplayer 상품 페이지 3건을 한 번씩 조회할 때 `Crawl-Delay: 10`을 지키도록 지정하지 않아, 간격이 지켜졌는지 확인할 수 없다. 추가 조회는 하지 않았다.
- **User-Agent**: TCGCSV 문서는 전용 User-Agent 설정을 요구하나, 이번 소량 호출은 curl 기본값으로 했다. #6 구현 때 프로젝트를 식별하는 값을 설정해야 한다. 이는 차단 우회용 변경이 아니라 해당 서비스의 요구 사항이다.
- Cardmarket 상품 페이지는 AI 크롤러 차단에 따라 조회하지 않았다. 차단 우회 도구와 내부 API는 쓰지 않았다.
