번개장터, 중고나라, KREAM, 포케폴리오의 `robots.txt`를 먼저 확인하고, 접근이 허용된 범위에서 약관과 공개 페이지 구조를 검토했다(2026-11-01).

2026-11-02에 작업지시자 지시로 다음을 보완했다.

- **포케폴리오 제외**: 제휴 API 문의를 보내지 않기로 결정했다. 문의 초안은 폐기했다.
- **약관 검토**: 작업지시자가 전달한 중고나라·KREAM 약관 원문을 검토했다. 번개장터 파일은 개인정보처리방침이어서 판단에 쓰지 못했다.
- **번개장터 제외**: 작업지시자 결정으로 후보에서 제외했다.
- **대안 조사**: 네이버 쇼핑 검색 API, 해외 시세 API의 한글판 지원 여부, 외부 수집 없이 국내 시세를 채우는 방안을 조사했다.

결과는 `mydocs/tech/domestic_price_sources.md`의 "후속 조사" 절과 "포케폴리오 제외 및 대안 조사" 절에 정리했다.

## 발견 사항

1. **약관상 수집할 수 있는 국내 한글판 거래가 소스를 찾지 못했다.** 중고나라와 KREAM은 약관이 금지하고, 번개장터는 작업지시자 결정으로 제외했다.
2. **네이버 쇼핑 검색 API는 쓸 수 없다.** 2026-07-31 종료가 보도되었고(2차 출처), NAVER API HUB의 검색 API 목록에도 없다. 종료 공지 원문은 `developers.naver.com`이 AI 도구로 열리지 않아 확인하지 못했다.
3. **해외 시세 API는 한글판을 지원하지 않는다.** PokemonPriceTracker는 영어·일본판만 지원한다고 명시하고, tcgfast·카드픽도 한글판 가격이 없다. PokeTrace는 확인하지 못했다.
4. **일본판 시세를 대리 지표로 쓸 수 있다.** 한글판은 일본판과 세트 코드·번호가 같은 경우가 있어(1단계 표본), 일본판 가격을 원화로 환산한 참고가를 표시할 수 있다. 국내 실거래가는 아니다.
5. 중고나라 페이지 데이터에 판매자 필드가 있다. 향후 어떤 방식이든 저장하지 않아야 한다.

## 국내 거래가 대체 방안

| 방안 | 내용 |
|------|------|
| A. 일본판 대리 시세 | 일본판 가격을 원화로 환산해 "일본판 기준 참고가"로 표시 |
| B. 사용자 거래가 직접 입력 | 앱 사용자가 자신의 거래가를 등록하고 집계 |
| C. 작업지시자 수동 입력 | 시연 대상 카드의 국내 거래가를 관리자 입력 |

권장안은 A를 자동 소스로, B를 국내 실거래 소스로 두고, 시연용 초기 데이터는 C로 채우는 것이다. 확정은 4단계에서 작업지시자 결정으로 한다.

## 계획과 달라진 점

- **포케폴리오 문의 초안 폐기**: 계획에 있던 산출물이지만 작업지시자 결정으로 폐기했다.
- **대안 조사 추가**: 계획에 없던 범위이다. 작업지시자 지시로 수행했다.
- **번개장터 제외**: 이용약관을 검토하지 않고 작업지시자 결정으로 제외했다.
- **번개장터 `robots.txt` 해석**: 승인된 계획의 "AI 크롤러 전면 차단이 유지되면 조회하지 않는다"를 보수적으로 적용해 조회하지 않았다.
- **KREAM 비조회**: `robots.txt`가 HTTP 500이어서 RFC 9309에 따라 전체 금지로 간주했다. 약관은 작업지시자 제공 원문으로 검토했다.

## 접근 규칙 준수 점검

- 모든 소스의 `robots.txt`를 먼저 확인한 뒤 조회했다.
- 로그인, 앱 내부 API 호출, 양식 제출, 차단 우회는 하지 않았다. 판매자 값은 출력·기록하지 않았다.
- 대안 조사는 공개 문서와 검색 결과만 사용했고, API는 호출하지 않았다.
- 포케폴리오에 문의를 보내지 않았다.
