# Task #13: 카드 상세 화면 — 1단계 완료 보고서

## 단계 목표

카드 상세 스토어와 화면 골격: 상태 분기(잘못된 id, 로딩, 404, 오류·다시 시도), 카드 정보 영역, 탭 제목, 카드 간 이동 시 요청 취소.

## 변경 파일

| 파일 | 내용 |
|------|------|
| `src/frontend/src/stores/cardDetail.ts` (신규) | 상세 `id`별·추이 `id:기간`별 보관, 로딩·오류(`notFound` 구분), 같은 키 재요청 생략(`force`로 다시), 다른 카드로 가면 이전 카드 요청 취소(`cancelOthers`), 최근 20장까지 보관 |
| `src/frontend/src/views/CardDetailView.vue` (신규) | 라우트 화면. `id` 검사(양의 정수, 안전 정수 범위), 상태 분기, 탭 제목 |
| `src/frontend/src/components/card-detail/CardHeader.vue` (신규) | 큰 이미지(`high`), 언어·한글판 배지, 이름, 한글 종 이름, 세트(로고·이름·ID·카드 수), 번호, 희귀도, 발매일, 도감 번호. 가격은 2단계에서 slot 으로 넣는다 |
| `src/frontend/src/router/index.ts` | `card` 라우트 → `CardDetailView` |
| `src/frontend/src/views/CardPlaceholderView.vue` | 삭제 |

### 스토어 요청 규칙

- 요청은 키(`card:{id}`, `history:{id}:{기간}`)별로 하나이다. 요청이 끝날 때 그 키의 최신 요청일 때만 로딩을 끄고 결과·오류를 쓴다. 취소된 요청의 오류는 버린다.
- 2단계 이후 추이 탭을 빠르게 바꿔도 기간별로 따로 받으므로 서로 덮어쓰지 않는다.

## 발견 사항

- **카드 번호의 분모.** 처음에는 번호를 `025/{세트 카드 수}`로 썼는데, 일본판 `古代の咆哮` 카드의 인쇄 번호는 `025/066`이고 세트 카드 수(TCGdex `cardCount`)는 시크릿 포함 95장이라 `025/95`로 잘못 보였다. 번호는 `localId`만 쓰고, 카드 수는 세트 줄에 `(SV4K · 95장)`으로 옮겼다.
- 세트 로고는 `logoUrl` + `.webp`로 받는다(확인: 200).
