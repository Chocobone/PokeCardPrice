## 계획서 요약

- **서비스**: Card-Market — 여러 거래처(TCGplayer, Cardmarket, 국내 거래가 등)의 포켓몬 카드 시세를 원화로 환산해 한 화면에서 비교하고, 날짜별 시세를 자체 축적해 추이를 보여 주는 반응형 웹 앱
- **화면**: ① 홈·검색(급등·급락 순위) ② 카드 상세(소스별 가격, 평균가, 추이 차트) ③ 내 컬렉션(총 평가액, 기간별 증감)
- **구조**: 외부 소스(TCGdex, pokemontcg.io, 환율 API) → 수집 스케줄러(Go, 고루틴 병렬, 원화 환산) → PostgreSQL(카드·세트, 날짜별 시세 이력) ↔ Go API 서버(REST, 인증, 캐시, 평균가·변동률 계산) ↔ 웹 앱
- **일정 원칙**: 백엔드를 한 주 먼저 시작 → API 준비 후 DB 구축 및 최소 시세 데이터 수집 → 프론트엔드 연결 → 테스트와 보고서 병행
- **테스트**: API 단위 테스트, 수집 가격 정확도 검증, 브라우저별 동작 확인

## 작업지시자 결정 사항 (2026-10-29)

1. 프론트엔드는 **Vite + Vue** 기준으로 진행한다.
2. **국내 거래가를 수집 범위에 포함**한다. KREAM 외 국내 소스를 조사한다.
   → 사전 조사 결과 (`mydocs/tech/domestic_price_sources.md`)
   - 1차 거래처: 번개장터, 중고나라 (판매 완료 건, 공개 API 없음, robots.txt 일반 경로 허용)
   - 집계 서비스: 포케폴리오 (번개장터·중고나라·네이버카페 실거래가, **제휴 API 안내 있음**)
   - KREAM: 시세 조회에 로그인 필요, 자동 수집 난도와 약관 위험이 큼
   - 그 외 포카트레이드, 포케카몬, 포케산양, POPO TCG는 출처가 불분명한 2차 가공물이라 수집 대상으로 비권장
   - 국내 소스 우선순위: 포케폴리오 제휴 API 문의 → 번개장터·중고나라 → KREAM은 약관 검토 후 결정
3. **로그인 기능을 1차 범위에 포함**한다. → #9 인증 API, #10 컬렉션 API, #14 로그인·컬렉션 화면
4. 마일스톤 구분과 타스크 분리안을 승인한다.
