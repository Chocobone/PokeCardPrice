> **작성일**: 2026-11-26
> **브랜치**: `local/task13` (`local/devel` `9d700d5`에서 분기)
> **마일스톤**: M100 (v1.0.0)

## 개요

`/cards/:id` 자리 화면(#12)을 실제 카드 상세 화면으로 바꿨다. 화면은 #8 API(`GET /cards/{id}`, `GET /cards/{id}/prices`)로 다음을 보여 준다.
- 카드 정보
- 대표가
- 변형 × 소스 가격 비교 표 (원화 포함)
- 연결 카드
- 기간을 고를 수 있는 원화 추이 차트와 기간 요약

#8 F1에서 미룬 원화 표시 방식(Q2)도 정해, 상세 화면과 홈·검색에 적용했다. 차트는 패키지 없이 SVG로 직접 그렸다(Q1). 백엔드·의존성은 바꾸지 않았다.

## 발견 사항

- **카드 번호 분모**: 세트 카드 수(TCGdex `cardCount`)는 시크릿 카드를 포함해 인쇄 번호의 분모와 다르다(`025/066` vs 95장). 그래서 번호는 `localId`만 쓰고, 카드 수는 세트 줄로 옮겼다 (1단계).
- **대표가의 변형**: API가 대표가의 변형을 주지 않는다. 같은 소스·기준일·금액인 줄을 찾아 정한다(`representativeVariant`, 2단계). 계약에 변형을 더하면 단순해진다.
- **차트 구현**: SVG를 늘려 그리면 글자와 점이 함께 늘어난다. 그래서 선만 SVG(`non-scaling-stroke`)로 그리고, 글자와 점은 HTML을 겹쳐 올렸다. 점 정보를 떠 있는 상자로 띄우면 360px에서 화면 밖으로 넘쳐서, 차트 위 고정 줄로 바꿨다 (3단계).
- **세로축 글자 잘림, 1년 요약의 연도, 가로축 끝(`from + 기간`)** 문제를 3단계에서 고쳤다.
- **목업 기준일 고정**: 목업 기준일이 `2026-11-16`이라 오늘 기준으로 모든 가격이 "오래된 가격"으로 보인다. 오래된 가격 표시를 확인하는 데 쓸 수 있어 그대로 두었다.
- **목업 서버**: Vite가 서비스 이름 접속을 막아, 헤드리스 확인은 컨테이너 IP로 접속했다. 작업지시자 확인용 목업 서버는 `docker compose run -d --rm --no-deps --name pokecardprice-mock -p 5174:5173 -e VITE_API_MOCK=true frontend`로 띄웠다. 이미지의 시작 명령이 5173 포트로 고정이라 호스트 5174를 컨테이너 5173에 연결했다.
- **실데이터 이력**: 개발 DB 이력은 3일치다. 실데이터 차트는 짧은 이력("이력이 짧음") 화면으로 확인했고, 긴 기간은 목업으로 확인했다.
