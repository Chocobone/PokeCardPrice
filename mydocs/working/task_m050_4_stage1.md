## 발견 사항

- **`enum` 값은 되돌릴 수 없다.** `ALTER TYPE ... DROP VALUE`는 PostgreSQL 18에서도 `not implemented`이다. 또 goose 트랜잭션 안에서 추가한 값은 같은 마이그레이션에서 쓸 수 없다 (`unsafe use of new value`). D1에서 `enum`을 제외한 근거이다.
- **sqlc 이름 충돌**: 참조 테이블 `price_kinds`와 enum `price_kind`가 같이 있으면 `struct name conflicts with enum name` 오류로 생성이 멈춘다.
- **한글 두 글자 검색**: trigram은 세 글자 단위라, `피카`처럼 두 글자 검색어는 인덱스가 거르지 못하고 인덱스 전체를 읽는다. 2단계에서 실제 규모로 확인한다.
- **#2 방침과 다른 제안 (Q3)**: 일본판 참고가를 KRW로 저장하지 않고 조회할 때 환산하자고 제안했다. 같은 정보를 두 번 저장하지 않기 위해서다. 승인되면 #7 A안의 범위가 바뀐다.
